Web Design

At UW-Madison, I had the opportunity to create and share many projects, often for classes and extracurriculars. To house these projects, I learned to use web development sites like Wordpress and Wix Website to create my first portfolio website. However, due to my growing interest in web development and limited capabilities of web development sites, I decided to learn how to code websites myself. To that end, I enrolled at MATC in the Front End Web Developer Trade Diploma in the summer of 2026. Using the skills I learned in my first two classes, WebDev114 and ITDev117, I coded this portfolio website. This website, and this specific web design portfolio page, will demonstrate the skills I learn as I progress in my studies.
